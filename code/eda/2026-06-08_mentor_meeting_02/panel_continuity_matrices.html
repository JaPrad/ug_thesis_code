Full Continuity Matrix

This matrix shows the number of observations present in all the waves between the corresponding waves.

Full Continuity Matrix (Excluding COVID Time)

This matrix shows the number of observations present in all the waves between the corresponding waves. However, data from 2020 and 2021 has not been considered here to exclude COVID related attrition.

P2P Continuity Matrix

This matrix shows the number of observations present in both corresponding waves.
